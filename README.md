# ريموت تلفزيونك

واجهة عربية أنيقة للتحكم بقطعة Android TV أو Google TV من أي جوال على شبكة البيت. فيها ريموت بأسهم مثل ريموت شاومي، لوحة لمس بالإيماءات، فتح مباشر ليوتيوب وشاهد وViu، واهتزاز وقفل للمس. تعمل الصفحة من داخل قطعة التلفزيون؛ الجوال لا يحتاج تثبيت تطبيق.

## الاستخدام

1. ثبّت تطبيق **ريموت تلفزيونك** على قطعة Android TV وافتحه.
2. اضغط **تشغيل الريموت**. أول مرة، وافق على رسالة **تصحيح USB** التي تظهر على التلفزيون.
3. امسح رمز QR الظاهر على الشاشة بكاميرا جوالك. يجب أن يكون الجوال والقطعة على واي فاي البيت نفسه.
4. أرسل الرابط المحلي الذي فتح على جوالك لأفراد البيت؛ أو أرسل لهم رابط صفحة GitHub Pages، ثم أدخل عنوان القطعة الظاهر بجانب رمز QR مرة واحدة.

يعرض تطبيق التلفزيون عنوان الاتصال المحلي ورمز QR. استخدم هذا العنوان من هواتف الأسرة، وقد يتغير إذا غيّر الراوتر عنوان القطعة. يمكن ضبط حجز DHCP في الراوتر ليبقى ثابتًا. لا تفتح المنفذ 8080 على الإنترنت ولا تستخدم تحويل المنافذ؛ التحكم مقصود لشبكة البيت فقط.

## ما الذي يفعله التطبيق على التلفزيون؟

- يشغل صفحة التحكم المحلية على المنفذ 8080.
- يستخدم خدمة Android Debug Bridge المحلية في القطعة لإرسال أزرار الريموت.
- يبدأ خادم الصفحة عند تشغيل الجهاز، ويعرض عنوانه ورمز QR في تطبيق التلفزيون.
- لا يبقي قفل المعالج أو الواي فاي نشطًا، ولا يجري فحوصًا متكررة عبر shell. فحص الاتصال خفيف، كل 20 ثانية عند فتح الصفحة.
- يقبل أوامر الأزرار واختصارات التطبيقات الثلاثة فقط؛ لا ينفذ أوامر shell يرسلها الزوار.

## التنزيل والبناء

كل دفع إلى GitHub يشغّل GitHub Actions ليبني APK تجريبيًا ويحفظه كـ Artifact باسم urtv-remote. نزّله من صفحة Actions ← آخر تشغيل ناجح ← Artifacts. لا يحتوي المستودع على عنوان IP للمنزل أو مفاتيح توقيع.

يمكن بناء APK محليًا من مجلد tv-remote-apk باستخدام JDK 21 وAndroid SDK:

    cd tv-remote-apk
    bash gradlew assembleDebug

## الخصوصية

الخادم على التلفزيون محلي. لا يرسل الأزرار أو معلومات الجهاز إلى GitHub أو أي خدمة سحابية. صفحة GitHub Pages مجرد صفحة تعريف وفتح للرابط المحلي؛ لا تتصل بالتلفزيون بنفسها.

## الاعتمادات والحقوق

تطبيق Android مبني على [TV Remote من Legvan](https://github.com/Legvan/tv-remote)، المرخّص MIT. إشعار الترخيص موجود في UPSTREAM-LICENSE-MIT. صورة الخلفية مقتبسة من أصول UrTV (tshi-dev/UrTV)، والنسخة الأصلية تنسبها إلى NEOM / Unsplash. بقية الواجهة عربية ومخصصة لهذا المشروع.
